# python-news
API-based news webiste, made as an activity to practice working with Python Flask. It is based on [youtube tutorial](https://www.youtube.com/watch?v=5EUOvXjahLY).

```
git clone https://github.com/fistaszek2009/python-news.git
cd python-news
```

```
python -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
//npm install - only required for editing scss
```

```
py app.py
```
